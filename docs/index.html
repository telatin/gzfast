gzfast

Fast, verified, multithreaded GZip decompression for Nim

No external dependencies. A private copy of zlib 1.3.2 is bundled and compiled into your application via Nim's inline {.compile.} mechanism. No zlib-dev, no shared libraries, no CMake, no Rust.

Documentation Repository 
import gzfast

let input = openGzFast("reads.fastq.gz", threads = 8)
defer: input.close()

for line in input.lines:
  discard line

discard input.finish()
